# 花候图志 · AE 工程导出

在工具中开始记录 AE 时间轴后手动游玩或自动通关，停止并导出 ZIP。录制视频时可同步记录，停止录制后自动导出。

解压后，在 After Effects 的“文件 → 脚本 → 运行脚本文件”运行 `build_ae_project.jsx`。脚本读取同目录的 `timeline.json`，新建工程、素材文件夹和主合成，导入素材并设置关键帧、音效与标记。可选择另存 `.aep`。

包中包含 `build_ae_project.jsx`、`timeline.json`、`README_AE.md`、`assets/*.png`，以及记录了声音时的 `audio/mix.wav` 和 `audio/sfx_*.wav`。

画幅基准为 720×1600。背景、花园棋盘、泥土格、每株花苞/花朵、每段藤蔓/叶片、种子、HUD、粒子、弹窗、结束页和手指依照游戏实际绘制项拆为独立图层，不把整段游戏录成一层视频。图层从下到上排列，与网页精灵 z 顺序一致。

每层记录素材、锚点、位置、缩放、旋转和不透明度；间断出现的元素按连续片段拆层。支持 `reduce` 精简线性关键帧或 `bake` 逐帧烘焙、24/25/30/60fps、中英文命名和画幅缩放。混音层与逐事件音效预合成默认同时提供，便于剪辑时选择；`both` 模式默认关闭混音层的播放，逐事件轨可听，避免重复播放造成音量翻倍。

固定层名包括 `背景 / Background`、`手指 / Hand`、`结束页 / End card`、`免责声明 / Disclaimer`。主合成为 `主合成_花候图志 / Main_PhenologyAtlas`。

如修改关卡或美术设置，请重新记录。3D 导出复用本时间轴，并强制逐帧采样、英文命名和双轨音频。脚本测试钩子为 `$.global.__PLANT_LIGHT_BUILD_STATS`。
