# v1 参考视频拆解记录

分析日期：2026-11-18。来源为用户提供的本地视频，720×1600，30 fps，84.066667 秒。视频从 Level 2 开始，结束在 Level 12，没有 Level 1 或第 18 关的实机内容。下文记录原片观察及 v1 决策。v2 保留关卡与玩法的数字拆解，采用花候图志的场景、工作台及教学文案。视频及本机研究图未随仓库发布。

## 取证结论

- 本质是格子上的限量种子正交光路覆盖谜题，包装成花园。种在空格上的种子向上、右、下、左各长出一根直藤，直到棋盘边界或前一颗种子的藤蔓；没有对角射线，也没有花朵折射/反射。
- 藤蔓经过花苞后，花苞绽放，藤蔓继续前进，不在花处终止。视频 0–2 秒的 Level 2 最清楚：种子位于 `(1,3)`，向上点亮白花 `(1,0)`，向左右点亮同排三花。
- 种子按顺序结算。新藤蔓不能穿过旧藤蔓，画面出现交叉处红叉。视频 5.5–7 秒提示 `Vines can't grow through each other.`；9 秒 Level 4 提示 `Order matters — vines block each other.`。
- 手指按住花园可移动落点，显示半透明正交虚线预览；滑出花园再释放会取消。视频 0–1.2 秒教程原文 `Slide your finger to aim. Slide off the garden to cancel.`。
- 不能把种子放在已有花苞或旧藤蔓所在格。视频中有效种子都位于空格，此行为也符合格上光路覆盖逻辑；非法点击具体提示文本未完整展示，属实现时合理约束。
- 花全部绽放即达成目标。视频给出了种子预算以及 `plant them both / plant all three` 教学，但没有演示少用种子已全开的情况，不能凭此把“必须用完”认定为隐藏胜利条件。复刻默认预算为上限、花全开即胜利。
- 未解完且种子用尽时，没有立刻弹 Game Over。画面仍保留棋盘，并用红圈标出漏花、红叉标出受阻处，提示撤销；例见 25–29 秒 Level 6。对应的实现应允许撤销/重开继续尝试。

## 道具与弹窗

| 能力 | 可见证据 | 应实现的语义 |
| --- | --- | --- |
| 重新开始 | 所有关卡右上圆角白底回转箭头 | 清空本关种子、藤蔓与开花状态 |
| 设置 | 左上齿轮，视频未打开 | 保留入口；不虚构参考设置菜单内容 |
| Undo | Level 4 解锁，约 8.5–9.5 秒弹 `NEW HELPER / Undo`；附 `Takes back your last seed so you can try another way.`、`+3 free` | 撤销上一颗种子及其引起的开花，恢复可继续玩的状态；视频 26–29 秒逐次撤销至空盘 |
| Hint | Level 7 解锁，约 32–35 秒提示 `Tap the hint`，随后高亮合法落点和手指引导 | 给出当前状态的一步正确落点；可解状态重新求解，不固定播放陈旧轨迹 |
| Watering can | Level 12 解锁，约 75–78 秒提示 `Tap the watering can`，蓝水壶浇蓝花 | 只让指定一朵花绽放，不生藤、不消耗种子；图例显示 +2，原文 `Nice! The can helps when seeds run short.` |
| 第四道具 | 底部第四按钮标 `Lv. 18`，全片锁定 | 只能复刻锁定占位，不能宣称已从本片还原真实能力 |
| 通关 | 多关均出现花束顶饰、奶油色卡片、`LEVEL n`、绿色赞美词、红 `Next garden` | 下一关按钮；后续关卡有 `SEED BASKET`、五粒种子进度、礼物图标等装饰性收集进度 |

胜利标题实见 `In full bloom!`、`What a garden!`、`Flower magic!`、`The garden is alive!`。背景覆半透明深绿遮罩；卡片和按钮保留厚下缘阴影。视频从第 5 关左右开始展示种子篮奖励进度，但没有打开真正的礼物奖励，不能虚构完整经济系统。

## 画面层级与布局

- 原片竖屏 9:20，720×1600。主游戏画面填满视口，无黑色 letterbox。
- 背景为中心浅亮、边缘与底部深绿的柔和草地，远景灌木部分出画，点缀浅绿色双叶/三叶草、小粉花、黄蜂和白蝶；漂浮昆虫是独立装饰。
- 顶部约 y=95–190：左齿轮白奶油圆角方按钮，居中 `Level n` 白色圆润粗体/投影，右重开按钮。计数卡约 y=205–315，两张并列，左 `SEEDS` 和金种子+绿色正交徽记，右 `FLOWERS`、小粉花及计数；卡片有深绿投影、奶油渐变和厚下缘。
- 教学气泡在计数下方，低矮奶油色药丸/圆角矩形，深绿色粗体居中。
- 花园大体在 y=560–1250，外圈蜂蜜黄厚圆角木框，内侧浅色高光，下缘偏深金。瓷砖为暖陶土、圆角、内阴影和小颗粒，缝隙深棕。不同关卡会因行列数调整 tile 大小，不能固定等距方形还原全部关卡。
- 花苞由圆润渐变水滴花瓣、两片厚嫩绿叶、短茎组成，白/粉/紫/蓝/橙五色；花朵开后变成 5 片圆瓣+金黄花心，开花伴有小粒子和轻微弹跳。

- 底部约 y=1420–1580：四个等距的奶油圆形道具按钮，深色线性图标，按钮下方英文/等级标签；未解锁灰化，已解锁数量用右上红色小圆 badge。
